# Wheelie Babes - Bike Trip Blog

In 2022 my friends crossed the US on bicycles. I created a WordPress blog for them to track their adventure, complete with a map and daily stats. 
Later, I exported the data to create this TypeScript-based app with a Leaflet map, Flask backend, and [Python script](https://github.com/b-sik/create-gpx-files/) for bulk creation of GPX files from Google Maps URLs.
